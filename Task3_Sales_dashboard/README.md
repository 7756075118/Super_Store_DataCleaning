# Task 3 - Sales Performance Dashboard

## Project Title

Sales Performance Dashboard

## Objective

The objective of this project is to create an interactive sales dashboard that provides a clear view of sales and profit performance by region, category, and product.

The dashboard converts cleaned Superstore data into meaningful KPIs and visualizations that can be used by business stakeholders for quick decision-making.

## Tools Used

- Power BI
- Microsoft Excel
- CSV Dataset

## Dataset

The dashboard is created using the Superstore dataset.

The dataset contains information such as:

- Order information
- Customer and location details
- Product details
- Sales
- Quantity
- Discount
- Profit
- Region
- Category
- Ship Mode
- Order Date

## Dashboard KPIs

The dashboard contains the following key performance indicators:

1. Total Sales
2. Units Sold
3. Total Profit
4. Profit Margin

## Dashboard Visualizations

The dashboard provides the following visual analysis:

- Total Sales by Region
- Total Sales by Category
- Total Profit by Category
- Total Profit by Region

## Interactive Filters

The dashboard includes interactive slicers/filters that allow users to analyze the data based on:

- Region
- Category

Users can select different filter values and the dashboard visuals update accordingly.

## Key Insights

The dashboard helps identify:

- Which regions generate the highest sales
- Which categories generate the highest sales
- Which categories generate the highest profit
- Which products are top performers
- How sales change over different months
- Differences between sales and profitability

## How to Use

1. Download or clone this repository.
2. Open `Sales_Performance_Dashboard.pbix` using Power BI Desktop.
3. Use the slicers to filter the dashboard.
4. Analyze sales, profit, products, regions, categories, and monthly performance.

## Conclusion

This project demonstrates the use of Power BI to transform cleaned sales data into an interactive business dashboard. It focuses on KPI creation, data visualization, filtering, and presenting business insights in an easy-to-understand format.
