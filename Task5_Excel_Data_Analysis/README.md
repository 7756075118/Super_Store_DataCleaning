# Task 5 – Retail Sales Analysis Using Excel

## Project Overview

Task 5 focuses on analyzing a structured retail sales dataset using Microsoft Excel. The project demonstrates the use of Excel formulas, sorting, filtering, PivotTables, KPIs, and charts to understand retail sales performance and generate useful business insights.

## Objective

The main objectives of this project are:

- Analyze retail sales data using Excel.
- Calculate important business KPIs.
- Use Excel formulas such as `SUMIFS`, `COUNTIFS`, and `AVERAGEIFS`.
- Create PivotTables for different business analysis requirements.
- Analyze sales and profit by category, region, and sub-category.
- Create an interactive and easy-to-understand Excel summary dashboard.
- Present key business findings from the analysis.

## Tools Used

- Microsoft Excel
- Excel Tables
- Excel Formulas
- PivotTables
- PivotCharts
- Excel Dashboard

The project uses a retail sales dataset containing **600 records**.

The project includes PivotTables for:

1. Sales by Category
2. Sales by Region
3. Profit by Category
4. Sales by Sub-Category

These PivotTables help identify high-performing categories, regions, and product sub-categories.

## Dashboard

The Excel dashboard provides a summary of the retail sales analysis.

### Dashboard Components

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Average Order Value KPI
- Sales by Category Chart
- Sales by Region Chart
- Profit by Category Chart
- PivotTable summaries

## Key Findings

The analysis shows that Technology is the strongest-performing category in terms of sales and profit, while Office Supplies has comparatively lower sales. The Central region records the highest sales among the regions, while the South region records the lowest sales. The analysis also highlights differences in performance across product sub-categories, helping identify areas of strong performance and opportunities for improvement.
