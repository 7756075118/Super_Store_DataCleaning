🎤 Interview Questions
Q1. When would you use filtering instead of deleting rows?

Filtering should be used when we want to temporarily view specific records without removing the original data. It allows us to analyze selected records while keeping the complete dataset available.

Q2. Why should raw data be preserved?

Raw data should be preserved because it contains the original information. It can be used for validation, auditing, comparison, correction, and future analysis.
