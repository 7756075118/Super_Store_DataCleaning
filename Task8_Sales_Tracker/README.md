# Task 8 – Sales Tracker in Google Sheets

## 📌 Project Overview

This project is part of my **Data Analytics Internship at Veda Technology**.

The objective of Task 8 is to create a simple and interactive **Sales Tracker using Google Sheets**. The tracker allows sales data to be entered into a raw data sheet and automatically calculates **Daily Sales, Weekly Sales, and Monthly Sales** using spreadsheet formulas.

The project focuses on data entry, data validation, aggregation, and basic sales reporting.

---

## 🎯 Objectives

- Create a structured sales data entry sheet.
- Separate raw sales data from the summary section.
- Add data validation for Category and Region.
- Calculate Daily Sales automatically.
- Calculate Weekly Sales automatically.
- Calculate Monthly Sales automatically.
- Calculate Total Sales and Total Orders.
- Verify calculated totals using manual calculations.
- Create a simple and easy-to-use sales tracking system.

---

## 🛠️ Tools Used

- Google Sheets
- Spreadsheet Formulas
- Data Validation
- SUMIFS
- SUM
- COUNTA

---

## 📊 Dataset

The sales dataset contains 40 sample records.

| Column | Description |
