# Superstore Data Cleaning and Preprocessing

## Overview

This project focuses on cleaning and preprocessing a raw Superstore retail dataset using Python and Pandas.

## Objective

The objective is to identify and resolve common data quality problems such as:

- Missing values
- Duplicate records
- Inconsistent text
- Incorrect data types
- Date formatting issues
- Potential outliers

## Technologies Used

- Python
- Pandas
- NumPy
- Excel
- Jupyter Notebook

## Data Cleaning Steps

1. Loaded the raw dataset.
2. Inspected dataset structure.
3. Checked missing values.
4. Checked duplicate records.
5. Standardized text values.
6. Converted date columns.
7. Handled missing values.
8. Investigated outliers.
9. Validated the cleaned dataset.
10. Exported the cleaned dataset.

The final dataset is cleaned and ready for further
